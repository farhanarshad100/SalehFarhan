# Saleh Farhan — UI Developer Portfolio

A personal portfolio website presenting UI development work, professional experience, projects, and contact information.

## Sections
- Home and introduction
- About
- Experience
- Projects
- Contact
- Resume download

## Built With
- HTML5
- CSS3
- JavaScript

## Run Locally
Open `index.html` in a browser. The stylesheet, scripts, images, and resume assets are stored in the `assets` directory.
